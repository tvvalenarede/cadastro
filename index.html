📌 Como passar os dados para outro computador:
1. Clique em Exportar Backup (JSON) — um arquivo será baixado.
2. Leve esse arquivo para o outro computador (pen drive, WhatsApp, e-mail...).
3. No outro computador, abra este site e clique em Importar Backup, escolhendo o arquivo.
4. Pronto! Todos os clientes, funcionários e serviços estarão lá.
